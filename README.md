# Bookstore REST API

A modular RESTful API backend built with **Node.js** and **Express.js** for managing bookstore resources through CRUD operations. The project demonstrates REST API design, custom middleware, request logging, validation, and separation of concerns using Express Router.

## Tech Stack

* Node.js
* Express.js
* JavaScript
* REST API
